# 2×3 세그멘테이션 — 셀별 특징 · painpoint · 수치 검증 · 전략 방향

> 이 문서의 범위는 **"각 칸이 어떤 성격이고, 무엇이 문제이며, 그게 수치로 증명되는가"와 전략 방향**까지입니다. 기대 효과 금액은 전략 확정 후 계산합니다.

> 작성 2026-10-01

X_장기는 단기 공급 지표에서 분리하고, O 줄은 유지합니다.

## 0. 전체 흐름

```
① 데이터 한정   source == 1 은 과거 시점 값 → source == 0 만 사용 (1장)
② 축 설정       최근 1년 리뷰 O/X  ×  최소 숙박 1–3 / 4–29 / 30+ (2장)

⑥ 전략 방향     칸별 방향 + 집중 대상 (6장)
```

## 1. 왜 `source == 0`만 쓰나

| | `source == 0` | `source == 1` |
|---|---:|---:|
| 행 수 | 678,130 | 163,496 (19.4%) |
| 가격 결측 | 4.0% | **79.1%** |
| 침대 수 결측 | 0.2% | **100%** |
| 예약 가능일 0 | 0.07% | **68.4%** |
| 마지막 리뷰 중앙값 | 2026-05-25 | **2024-09-27** |

`source == 1`은 **과거 시점에 수집돼 이월된 값**입니다. 가격·시설 정보가 없어 상품력 분석이 불가능하고, "최근 1년 리뷰"의 "최근"이 2년 전이라 같은 축에 올릴 수 없습니다.

**부수 효과:** 이전 5층 분류의 L1(상태 미확인)은 99.8%가 `source == 1`이었습니다. `source == 0`으로 한정하면 L1이 사라지고, 예약 가능일 0인 매물이 452건(0.07%)뿐이라 **예약 가능일 축도 필요 없어집니다.**

> EDA 발표에서는 "`source == 1`은 시점이 다른 데이터라 분리했다"를 위 표 하나로 설명하면 됩니다.

## 2. 왜 이 두 축인가 — 방어 논리

### 2-1. 세로축: 최근 1년 리뷰 수 (`number_of_reviews_ltm`)

데이터에 예약 건수·매출 컬럼이 없어서, 손님이 묵은 흔적은 리뷰뿐입니다. 리뷰 계열 후보 중 `ltm`을 고른 이유는 네 가지입니다.

**① 결측 0%이고 현재 시점 값입니다.** 추정·대체가 들어가지 않습니다.

**② 플랫폼 수익과 바로 연결됩니다.** 수수료가 거래액의 15.5%이므로 **최근 1년 거래 0건 = 수수료 0원 + 노출 자원만 소모**입니다. 0과 1 이상의 경계가 곧 "돈을 버는가"의 경계라 O/X 이분으로 잘랐습니다. 0건이 전체의 30.4%로 분포에서 가장 큰 덩어리이기도 합니다.

**③ 대안 컬럼은 과거와 현재를 섞습니다.**

| 후보 | 원래 결측 | 문제 |
|---|---:|---|
| **`number_of_reviews_ltm`** ★ | **0%** | — |
| `number_of_reviews` (누적) | 0% | 최근 1년 무거래 매물의 **39.2%가 누적 리뷰는 있음** → 몇 년 전에 끊긴 매물이 '활동 중'으로 잡힘 |
| `reviews_per_month` | 18.5% | 첫 리뷰 이후 **생애 평균**. 위와 같은 39.2%가 0보다 큼 |
| `last_review` | 18.5% | 리뷰 0건이면 값 자체가 없음 |
| `review_scores_rating` | 18.5% | 6칸 중앙값이 **4.80–4.91로 붙어 있어** 변별력 없음 |
| `availability_365` | 0% | 달력 닫힘과 만실을 구분 못 함. 거래 매물 안에서 리뷰 수와의 순위상관 0.003 (EDA 6장) |

**④ 0은 일시적 공백이 아닙니다.** 과거에 팔렸던 무거래 매물 80,918건의 마지막 리뷰는 **중앙값 756일(약 2년) 전**입니다. 1년 창이 계절 한 바퀴를 다 덮으므로 "비수기라 0"도 아닙니다.

> **한계 — 리뷰는 대리 지표입니다.** 다만 O_단기의 최근 1년 리뷰 중앙값이 9건이라 "묵었는데 리뷰만 안 남겼다"로 0건을 설명하기는 어렵습니다.

### 2-2. 가로축: 최소 숙박 1–3 / 4–29 / 30+

| 최소 숙박 | 1 | 2 | 3 | **4** | **5** | **6–7** | 8–14 | 15–29 | 30 | **31** | 32+ |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 무리뷰율 | 28% | **21%** | 29% | **33%** | **43%** | **53%** | 47% | 59% | 59% | **86%** | 52% |
| 매물 | 313,768 | 171,809 | 77,968 | 25,845 | 20,004 | 19,251 | 5,977 | 5,585 | 12,607 | 22,481 | 2,835 |

- **1–3박은 21–30%로 평평**하고 2박이 가장 낮습니다. **4박부터 계단처럼 오릅니다.**
- 결정 트리가 고른 분기점도 **4.5박**입니다(이전 모델링에서 5회 반복 모두 동일, 이번 트리도 동일).
- 다만 가격·지역을 통제한 회귀에서는 3박도 2박보다 오즈비가 1.47로 이미 높고, 4박 1.82 · 5박 2.64에서 가팔라집니다(4장 X_중기). **3박을 단기에 둔 근거는 원자료 무리뷰율이 1–3박에서 평평하다는 점과 트리 분기점**입니다. "3박도 위험하지 않나"라는 질문에는 이 수치로 답하면 됩니다.
- **30박은 단기 숙박과 월 단위 임대의 관행적 경계**입니다. 장기 매물은 한 번 예약에 한 달을 묵어 리뷰가 적게 쌓이므로, 단기와 같은 잣대로 평가하면 안 됩니다. 그래서 별도 열로 뺐습니다.

### 2-3. 축에서 뺀 것

| 컬럼 | 뺀 이유 |
|---|---|
| `maximum_nights` | **6칸 모두 중앙값 365일**. 33.8%가 플랫폼 기본값(1,125일)이라 호스트가 의식적으로 정한 값이 아님 |
| `availability_365` | `source == 0`에서 0인 매물 0.07%. 축으로 나눌 대상이 없음 |
| 평점 | 변별력 없음 (위 표) |

## 3. 두 축은 함께 봐야 한다

| 검정 | 효과 크기 | 판정 |
|---|---:|---|
| 리뷰 O/X × 최소 숙박 구간 (카이제곱) | Cramér V **0.265** | 중간 — 두 축이 **독립이 아님** |
| 6칸 × 슈퍼호스트 (카이제곱) | V **0.294** | 중간 |
| 6칸 × 통집 (카이제곱) | V 0.157 | 작음 |
| 6칸 × 편의시설 (Kruskal-Wallis) | ε² **0.082** | 중간 |
| 6칸 × 동급 대비 가격 (Kruskal-Wallis) | ε² 0.059 | 작음~중간 |

<sub>표본이 커서 p값은 모두 0에 가까워 효과 크기로 판단합니다. V: 0.1 작음 · 0.3 중간 / ε²: 0.01 작음 · 0.06 중간 · 0.14 큼</sub>

- 최소 숙박이 길수록 무리뷰가 많습니다(단기 26% → 중기 44% → 장기 75%). **축 하나만 보면 다른 축의 효과가 섞이므로 2×3으로 함께 봐야 합니다.**
- 칸을 가르는 힘은 **상품력(슈퍼호스트·편의시설)이 가격보다 큽니다.** 이전 5층 분석과 같은 결론입니다.

**동급 그룹이란** — 같은 도시 × 방 타입 × 수용 인원(8명 이상은 8)인 매물 묶음입니다(30건 이상, 653개 그룹). 기존 `peer_group`은 최소 숙박 구간이 키에 들어 있어 단기 vs 중기 비교에 쓸 수 없어서, 최소 숙박을 뺀 키를 새로 만들었습니다.

**계절성 지수란** — 지역별 `(최근 30일 리뷰 × 12) ÷ 최근 1년 리뷰`(O 매물 기준)입니다. 기준일이 7월 22일이므로 1보다 크면 "여름에 수요가 몰리는 지역", 즉 휴양지 성격입니다. 주관적인 "휴양지" 목록 대신 데이터로 정의한 값입니다.

손그림의 가설을 하나씩 검정한 결과입니다.

| 칸 | 손그림 가설 | 판정 |
|---|---|---|
| X_단기 | 휴양지 · 비쌈 | ✅ 맞음. 단 **상품력 부족이 가격보다 큼** |
| X_중기 | 호스트 설정 문제 → 단기로 | ✅ 맞음. 가장 강한 증거 |

### X_단기 — 휴양지에서 동급보다 비싸고 상품력이 낮다 (144,645건, 21.3%)

| 지표 | X_단기 | O_단기 | 효과 크기 |
|---|---:|---:|---:|
| 동급 대비 가격 | **1.13배** | 1.00배 | 순위이연상관 +0.17 |
| 동급 대비 편의시설 | **−6개** | +2개 | **−0.29** |
| 동급보다 1.6배 넘게 비싼 비율 | 23.8% | 13.4% | |
| 편의시설 12개 이상 부족 비율 | **34.7%** | 15.0% | |
| 슈퍼호스트 | 11.6% | 41.0% | |
| 개설 후 한 번도 안 팔림 | 61.2% | – | |

**휴양지 가설 검정** — 지역 51개에서 **계절성 지수와 단기 무거래율의 순위상관 0.51 (p = 0.0001)**. 풀리아(44%)·시칠리아(39%)·남에게해(36%)·크레타(32%)가 위쪽에 몰립니다. 반대로 부다페스트·프라하·세비야처럼 연중 수요가 있는 도시는 14–15%입니다.

**painpoint** — 짧은 성수기 수요에 비해 공급이 많은 휴양지에서, **동급보다 13% 비싸고 편의시설이 6개 적은** 매물이 팔리지 않습니다. 효과 크기는 편의시설이 가격보다 큽니다. 손그림의 "비쌈"은 맞지만 **"상품력 부족 + 비쌈"** 이 정확합니다.

**전략 방향** — **동급 대비 진단 알림.** "같은 지역·같은 인원 매물보다 가격은 상위 X%, 편의시설은 Y개 부족" 형태로 호스트에게 보여줍니다. 휴양지는 비수기 가격 조정 안내를 덧붙입니다.

### X_중기 — 최소 숙박 설정이 예약을 막는다 (33,369건, 4.9%)

**가장 강한 증거가 나온 칸입니다.**

| 검정 | 결과 |
|---|---|
| 같은 동급 그룹 안에서 중기 vs 단기 무리뷰율 | **298개 그룹 중 286개(96%)에서 중기가 더 안 팔림.** 차이 중앙값 **+16.9%p** · 부호 검정 p = 3×10⁻⁶⁹ |
| 가격·편의시설·지역 계절성 통제 후 (로지스틱) | 중기 설정의 무거래 오즈비 **2.63** (95% CI 2.58–2.68) |
| 지역 고정효과로 바꿔도 | 오즈비 **2.80** |
| 시장 관행 통제 — 중기가 흔한 지역(거래 매물 중 20%+)에서도 | 중기 34% vs 단기 23% (**+11%p**) |

**용량-반응** (2박 = 1, 가격·편의시설·지역 통제)

| 1박 | 2박 | 3박 | 4박 | 5박 | 6–7박 | 8–29박 |
|---:|---:|---:|---:|---:|---:|---:|
| 1.00 | 1 | 1.47 | **1.82** | **2.64** | **4.00** | **7.85** |

최소 숙박이 하루 늘 때마다 무거래 가능성이 단조롭게 커집니다. 같은 도시·같은 가격대·같은 상품력이라도 그렇습니다.

| 지표 | X_중기 | O_중기 |
|---|---:|---:|
| 1박 가격 중앙값 | **206€** (6칸 최고) | 177€ |
| 동급 대비 편의시설 | −6개 | +3개 |
| 슈퍼호스트 | 11.8% | 34.6% |

**painpoint** — 4박 이상 최소 숙박이 단기 수요를 잘라냅니다. 중기가 관행인 지역에서도 불리하므로 **시장에 맞춘 선택이라기보다 설정 미스**로 보입니다. 손그림의 "호스트 바보"는 발표에서 **"설정 미스"** 로 바꾸는 것을 권합니다.

**전략 방향** — **최소 숙박 하향 넛지 (→ 3박 이하).** 레버가 설정값 하나라 실행 비용이 가장 낮습니다. "같은 조건 매물 중 최소 숙박 3박 이하는 무거래율이 X%p 낮다"를 근거로 제시합니다.

> ⚠️ 연관이지 인과가 아닙니다. "활동 의지가 약한 호스트가 최소 숙박도 길게 잡는다"는 역방향 설명을 완전히 배제할 수 없습니다. 발표에서는 "설정을 낮추면 팔린다"가 아니라 "**같은 조건에서 최소 숙박이 짧은 매물이 일관되게 더 팔린다**"로 표현하세요.

### O_중기 — 럭셔리는 착시, 문제로 단정할 수 없다 (43,293건, 6.4%)

손그림의 "문제가 큰가?? 있나??"에 대한 답입니다.

| 비교 | 셀 전체 중앙값 | **같은 동급 그룹 안 (285개)** |
|---|---|---|
| 1박 가격 | 177€ vs 단기 153€ — 비싸 보임 | **중기/단기 0.90배** — 오히려 쌈 (중기가 비싼 그룹 18%) |
| 최근 1년 예약 수 | 4건 vs 9건 | **0.40배** |
| 할인 적용 | 17.3% vs 6.2% | |

**"럭셔리"는 구성 효과입니다.** 큰 집(침실 중앙값 2개)과 휴양지(발렌시아·메노르카·마요르카는 매물의 17–20%가 O_중기) 비중이 높아 셀 전체로는 비싸 보이지만, 같은 조건끼리 비교하면 주 단위 할인 때문에 1박 가격이 더 낮습니다.

**매출은 숙박 기간 가정에 따라 뒤집힙니다.**

| 단기 손님 평균 숙박 가정 | 중기 손님 추가 숙박 | 추정 매출 중기/단기 |
|---|---|---:|
| 3박 (기본) | 0 | 0.73배 |
| **2박** | 0 | **1.03배** |
| 4박 | 0 | 0.56배 |
| 3박 | +2박 | 0.98배 |

**결론** — 예약 수는 동급의 40%지만 한 번에 길게 묵어 메웁니다. **"덜 자주, 길게 파는" 선택이고, 수치로는 문제라고 말할 수 없습니다.** 전략 대상에서 뺍니다. 발표에서 이 칸을 문제로 제시하면 질의응답에서 가정 하나로 반박당합니다.

**전략 방향** — **유지.** 굳이 개입한다면 4박 매물의 3박 하향을 소규모로 실험해 볼 수 있습니다.

## 6. 전략 방향

### 집중 대상: X_단기 + X_중기 = 178,014건 (`source == 0`의 26.3%)

두 칸은 **"단기로 팔 수 있는 조건인데 안 팔린다"** 는 같은 문제이고, 하나의 장치로 묶을 수 있습니다.

> **동급 대비 리스팅 진단** — 같은 도시·방 타입·인원 매물과 비교해 ① 편의시설 부족분 ② 가격 위치 ③ 최소 숙박 설정을 호스트에게 보여주는 알림.
> 기준선은 데이터가 정한 값을 씁니다: **편의시설 동급 대비 −12개 · 가격 1.7배 · 최소 숙박 4.5박.**

이 구성을 권하는 이유:
1. **규모** — `source == 0`의 4분의 1이 넘고 수수료가 0원인 매물입니다.
2. **증거** — 세 레버 모두 동급 비교 + 지역 통제 회귀 + 도시 단위 검증에서 일관됩니다.
3. **실행 가능성** — 본사가 알림 하나로 실행할 수 있고, 규제(외부 변수)와 무관합니다.
4. **과제 조건** — "문제의 개수보다 하나를 짚더라도 확실한 개선"에 맞습니다. 나머지 네 칸은 진단으로만 보여줍니다.

## 7. 이전 5층 분류와의 관계

| 이전 5층 (전체 841,626건 기준) | 2×3 (`source == 0` 기준) |
|---|---|
| L1 상태 미확인 | **사라짐** — 99.8%가 `source == 1` |
| L2 장기 설정 (ltm 0 · 30박+) | ≈ **X_장기** |
| L3 단기 무거래 (ltm 0 · 30박 미만) | = **X_단기 + X_중기** ← L3를 최소 숙박으로 쪼갠 것 |
| L4 저활동 + L5 안정 거래 | = **O 줄** (ltm 1–2 / 3+ 구분 대신 최소 숙박으로 나눔) |

이전 분석에서 L3 안에 섞여 있던 **"최소 숙박 설정 문제"를 별도 칸(X_중기)으로 꺼낸 것**이 2×3의 핵심 개선입니다. 이전에 로지스틱 회귀 변수로만 보였던 최소 숙박 효과가 이제 칸 하나로 보이고, 그 칸에 다른 처방(설정 하향)을 붙일 수 있습니다.

MODELING_RESULTS의 결론(상품력·관리 ≥ 가격, 기준선 −12개 · 1.6배 · 4.5박)은 2×3에서도 그대로 재현됐습니다.
